# DragonBleu98Coplay

Projet frontend développé avec **Vite**, **Vue.js** et **TailwindCSS**.

## Description

DragonBleu98Coplay est une application web construite avec Vite pour le bundling, Vue.js pour la partie interactive, et TailwindCSS pour le style. Le projet contient une structure claire avec un dossier `public` pour les assets publics et un dossier `src` pour le code source.

Ce projet est l'application web de la cosplayeusse DragonBleu98

## Structure du projet

- `public/` : fichiers statiques accessibles publiquement (ex : `vite.svg`)
- `src/` : code source
  - `assets/` : ressources (images, polices, etc.)
  - `components/` : composants Vue
  - `img/` : images spécifiques
  - `App.vue` : composant racine Vue
  - `index.css` et `style.css` : fichiers CSS
  - `main.js` : point d'entrée JS
- `index.html` : page d’accueil principale
- `indexphotos.html` : page supplémentaire (ex : galerie)
- `package.json` & `package-lock.json` : gestion des dépendances
- `postcss.config.js` : configuration PostCSS
- `tailwind.config.js` : configuration TailwindCSS
- `vite.config.js` : configuration Vite
- `corrections/` : dossier pour corrections ou ressources diverses
